# Release Candidate 1

## Funktionen
- XML gesteuerte Abteilungen
- XML Excel Mapping
- Historische Wochenstaende
- Excel Import ueber XLSX
- KPI Dashboard
- Chart Visualisierung
- GitHub Pages Deployment

## Datenstruktur

/data/<abteilung>/<periode>/*.xlsx

Beispiel:

data/sales/2026-W25/sales.xlsx

## Deployment

Push auf main startet automatisch GitHub Pages Deployment.
